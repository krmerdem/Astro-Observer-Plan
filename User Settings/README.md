# User Settings

Bu klasor uygulamanin kullanici ayarlarini tutar.

- `*.json` dosyalari uygulamanin **calisma aninda okudugu/yazdigi** aktif
  ayarlardir. Yazilim "Save Settings" ile bu dosyalari guncel ayarlarinizla
  uzerine yazar.
- `*.default.json` dosyalari **referans/varsayilan** sablonlardir. Aktif bir
  ayar dosyasi bozulursa ilgili `.default.json` icerigini `.json` dosyasina
  kopyalayarak varsayilanlara donebilirsiniz.

Depoda tutulan varsayilan konum notr bir ornektir (Greenwich, Birlesik
Krallik). Kendi gozlem konumunuzu uygulamadaki "Edit Settings" / "Save
Settings" akisiyla ayarlayin; kisisel konum bilgileriniz depoya gondermeden
yalniz yerelde tutulur.
